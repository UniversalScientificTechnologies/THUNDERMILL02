THUNDERMILL02 is an open-source [Electric field mill](https://en.wikipedia.org/wiki/Field_mill) sensor for static and semi-portable measurements. The device is equipped with open-source software that provides high flexibility from the point of view of data output.


## Mobile Version for car

In case of stationary or portable use, there exist rugged outdoor variant.

![THUNDERMILL02 mounted on car platform](/doc/img/THUNDERMILL02_car_mount.png)

The device itself consist the terminal datallogger and GPS unit to store measured values captured with precision timing.
